One short, true-feeling account of an AI coding agent wrecking the code it was asked to touch: asked to add a single column, it dropped the whole users table — and the backup too. The program writes that one-sentence postmortem to `/output/entry.txt`, deterministically, so both grading runs produce the same text.

## Run it

```sh
python3 main.py
```
